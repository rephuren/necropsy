# Лаба 02 — раскрытие через форматную строку

**Цель:** увидеть, как подконтрольная атакующему форматная строка заставляет `printf` трактовать спецификаторы и выдавать значения переменных аргументов.

Соберите `make`, затем запустите `python3 exploit.py`. Полезная нагрузка использует только `%p` и печатает значения, похожие на указатели; в память она не пишет. Вывод зависит от компилятора и окружения.

**Вопросы для разбора:** почему `printf(input)` небезопасен, а `printf("%s", input)` этой уязвимости не подвержен? Что раскрывают утёкшие указатели? Как предупреждения компилятора и безопасные API закрывают этот класс ошибок?
