# Учебные лаборатории эксплуатации x86-64

Две намеренно уязвимые программы с разборами на pwntools — только для локального запуска. Запускайте только эти бинарники и только в изолированной учебной среде.

## Что внутри
- `ret2win/` — переполнение буфера на стеке и перехват адреса возврата.
- `fmt-leak/` — раскрытие данных через форматную строку.

## Требования
- Linux x86-64
- GCC
- Python 3.10+
- `python3 -m pip install pwntools`

Сборка и проверка:

```sh
make all
make test
```

Makefile отключает PIE и канарейку стека, чтобы вводные задачи были детерминированными. Это C-бинарники под x86-64, а не программы, написанные на ассемблере вручную: они годятся для отработки эксплуатации, но не закрывают требование «исходник именно на ассемблере». Не выставляйте эти программы в сеть.
