# Паттерны ImHex

- `elf64.hexpat`: заголовок ELF64 little-endian, таблицы сегментов (с битовыми флагами rwx) и секций.
- `pe.hexpat`: DOS-заголовок, COFF, необязательный заголовок PE32 или PE32+ (выбирается по `magic`), каталоги данных, таблица секций.

Как открыть: в ImHex файл → открыть бинарник → меню «Файл → Загрузить паттерн» (или вставить в окно редактора паттернов).

**Честно о проверке.** Паттерны написаны вручную по спецификациям. Самого ImHex в среде разработки не было, поэтому в нём они не запускались. Порядок и размеры полей я писал по спецификации тем же способом, что и разборщики на Go (`internal/elfx`, `internal/pex`), но автоматически с ними не сверял. Тест `imhex_test.go` проверяет только то, что файлы на месте, фигурные скобки сбалансированы и ключевые структуры названы. Если ImHex ругнётся на синтаксис, это ошибка в паттерне, а не в формате: откройте issue.
